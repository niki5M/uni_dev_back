# Руководство по URL для мобильного приложения

## ⚠️ Важно: `0.0.0.0` - это НЕ адрес для клиентов!

`0.0.0.0:8000` - это адрес для **биндинга сервера** (слушать на всех интерфейсах), но для клиентов нужно использовать другой адрес.

## Правильные URL для использования в приложении:

### 1. Если мобильное приложение на том же компьютере:
```
http://localhost:8000
```
или
```
http://127.0.0.1:8000
```

### 2. Если мобильное приложение на другом устройстве (телефон/планшет):

Нужно использовать **IP-адрес вашего компьютера** в локальной сети.

#### Как узнать IP-адрес:

**На macOS/Linux:**
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

**На Windows:**
```bash
ipconfig
```

Ищите адрес вида `192.168.x.x` или `10.0.x.x`

#### Пример:
Если IP вашего компьютера `192.168.1.100`, то URL будет:
```
http://192.168.1.100:8000
```

## Настройка в Flutter приложении:

В файле `.env` вашего Flutter проекта:

```env
# Для эмулятора/симулятора (тот же компьютер)
GRADEBOOK_API_URL=http://localhost:8000/api/v1/gradebook

# ИЛИ для реального устройства (замените на ваш IP)
GRADEBOOK_API_URL=http://192.168.1.100:8000/api/v1/gradebook
```

## Полные пути к API:

- Все оценки: `{BASE_URL}/grades`
- По семестру: `{BASE_URL}/grades?semester=1`
- По предмету: `{BASE_URL}/grades?subject=ООП`
- Средний балл: `{BASE_URL}/grades/average`
- Статистика: `{BASE_URL}/grades/statistics`

Где `{BASE_URL}` = `http://localhost:8000/api/v1/gradebook` (или IP вашего компьютера)

## Проверка работы API:

Откройте в браузере:
- `http://localhost:8000/docs` - интерактивная документация
- `http://localhost:8000/api/v1/gradebook/grades` - проверить, что данные возвращаются

## Важно для мобильного приложения:

1. **Убедитесь, что телефон и компьютер в одной Wi-Fi сети**
2. **Отключите firewall** или разрешите порт 8000
3. **Используйте IP-адрес компьютера**, а не `localhost` или `0.0.0.0`
